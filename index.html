Greensighter UI

Design tokens from the Figma design system: color, typography, spacing and radius.

Semantic color

Use these in all work. Each has a Dark and a Light value: Dark for thumbnails and social posts, Light for blog infographics. Switch with data-theme.

Primitives

Raw palette. These only feed the semantic tokens and shouldn't be used directly.

Typography

Always apply a text style class (.gs-text-*) instead of setting sizes by hand. Headlines use tighter letter spacing.

Spacing

8px grid, 4px for fine detail. Use --gs-spacing-* for gaps and padding.

Radius

Chips and pills use full, cards use 2xl (24px), large glass panels use 4xl (48px).
