# Claude design agent team

Three cooperating Claude agents that take a product idea to a deployed, frontend-only web experience:

- **Project Manager**: product brief, feature specs with numbered acceptance criteria, backlog.
- **UI/UX Designer**: flows and screens in Figma using only the Untitled UI v8.0 design system, then the static frontend build and preview deploy.
- **Reviewer**: three stage gates (spec, Figma, live preview) with evidence-based verdicts: APPROVED, CHANGES REQUESTED or SPEC GAP.

The main Claude session acts as the **Coordinator**: it calls the agents in order, enforces the gates, keeps a log, and asks you only for escalations. There is no backend: anything server-like is simulated in the browser.

**Golden rule:** the Untitled UI v8.0 design system (`design-system/`) is the single source of truth for tokens, type, spacing and components. Nothing may be invented outside it.

## Quick start (Claude Code, recommended)

```
git clone https://github.com/Greensighter/greensighter-ui.git
bash greensighter-ui/claude-design-team/install.sh /path/to/your/project
cd /path/to/your/project && claude
```
Then approve the `figma` MCP server, run `/mcp` to sign in to Figma, run `/agents` to confirm the three agents, and paste `KICKOFF.md` with your project details filled in.

## Quick start (Claude app, no terminal)

1. Create three Projects: PM, Designer, Reviewer.
2. Paste the matching file from `claude-ai-projects/` into each Project's instructions.
3. Upload `design-system/design-system.md`, `components.md` and `tokens.css` as Project knowledge.
4. Turn on the Figma connector in the Designer and Reviewer Projects.
5. Pass work between Projects by copying the handoff note (`templates/handoff.md`). You act as the Coordinator.

## Keeping the design system current

`design-system/` was generated by a read-only audit of the Figma file on 2026-10-21 (7 variable collections, 691 variables, 44 text styles, 220 component sets). The Figma file wins over these documents. When the library changes, ask the Designer agent to re-run the audit and update the documents, then commit.

Known gaps in the design system (no motion, z-index, breakpoint or opacity tokens, and some token pairs below WCAG AA contrast) are listed in `design-system/design-system.md` under "Not verified".

## Rules of the road

- Nobody approves their own work. Only the Reviewer issues verdicts.
- Two rejections at the same gate escalate to the human.
- Missing from the design system? The Designer flags it to the human; no silent inventions.
